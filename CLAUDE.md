# CLAUDE.md: project memory for Infiante360 Tech Academy

## What this is
Static site generated by `src/build.py` from `content/` and `src/content_*.py`, deployed to GitHub Pages by `.github/workflows/pages.yml`. Live: https://infiante360techacademy.com/ (the repo's `CNAME`; the workflow sets `SITE_BASE`). A separate LMS static site lives in `lms-site/` and ships at `/lms-hub/`. A corporate section (`corporate/`) is a separate brand section with its own sitemap.

## Operating rules
- Check, reuse, patch, then generate. Never regenerate files that exist. Read `PROGRESS.md` first.
- No fabricated clients, results, testimonials, certifications, learner counts, prices, search volumes or rankings. Unknown values are `null`.
- No Adobe partner/learning-partner badge or endorsement wording unless authorisation is documented. Promotional claims on supplied banners (10K+ learners, lifetime access, 100% practical, job outcomes) are unverified and must not be published.
- No secrets in Git, chat or generated files. Nothing deploys, posts or sends without the owner's go-ahead.
- Do not publish thousands of near-duplicate pages. One page per distinct intent. See `data/seo/page_generation_queue.json`.

## Build and validation
- `src/build.py` runs in CI. The agent session's privacy plugin refuses commands that run it (the script holds a contact address beside a client name). Do not work around the refusal. The owner can run `! python3 src/build.py _site` locally, or supply the contact via an environment variable the script reads.
- Local checks that are safe: `python3 -I -m unittest discover -s tests`, `python3 -I scripts/seo_keyword_map.py`, `python3 -I agents/orchestrator.py pipeline`.
- CI order: dataset tests, build + validator, SEO inventory, agent pipeline, LMS copy, deploy. Read results with `gh run view <id> --log` (artifact download is blocked from the agent proxy).

## Data
- `data/seo/*`: ingested workbook (`scripts/seo_ingest.py`), keyword mapping (`scripts/seo_keyword_map.py`, decisions in `cluster_url_map.json`), `route_snapshot.json` (from CI).
- `agents/registry.json` (40 specs), `agents/orchestrator.py`. Runtime state in `data/agents/` is git-ignored.

## Gotchas learned
- The inventory must ignore SVG `<title>`; otherwise titles look 70-250 characters long.
- The corporate section's URLs are listed in `corporate/sitemap.xml`, not the root sitemap.
- The Zoho verification file must stay byte-exact; it is excluded as a utility page.
