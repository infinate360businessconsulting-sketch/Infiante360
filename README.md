# Infinite360 website (GitHub Pages)

Live URL: https://infiante360techacademy.com/ (custom domain set in Settings → Pages; the github.io URL redirects here)

Static site generated by `src/build.py` from content modules:

| File | Pages |
|---|---|
| `src/content_core.py` | Home, About, Training, Corporate training, Guides, Industries, FAQ, Contact, Privacy |
| `src/content_services.py` | Services hub + 8 consulting service pages |
| `src/content_aep.py` | AEP pillar + 11 cluster pages (schemas, datasets, ingestion, identity, profiles, segments, activation, architecture, implementation, interview questions, career path) |

Shared design: `assets/site.css`, `assets/site.js`. No frameworks or build dependencies (Python 3 standard library only).

## Build locally
```
python3 src/build.py          # outputs _site/
```
The build fails if any title/description/H1 is duplicated, a description is outside 70–160 chars,
a title exceeds 65 chars, JSON-LD is invalid, an internal link is broken, or a page is orphaned.

## SEO / AEO
- Every page: unique title, meta description, keywords, canonical, Open Graph/Twitter, one H1,
  a 40–80 word "Quick answer", breadcrumbs, related-page links, JSON-LD (`@graph`: WebPage +
  Article/Service/Course/HowTo/FAQPage + BreadcrumbList; Organization/WebSite on home).
- `sitemap.xml` lists every indexable page (404 and thank-you excluded). `llms.txt` summarises pages.
- Keyword map: the 50,000-keyword AEP list is 9 subtopics × 34 modifiers × 12 audiences × 15 locations.
  Subtopics map to the AEP cluster pages; modifiers map to sections; career/interview/course/services
  modifiers map to the career, interview, training and consulting pages. No location doorway pages.

## Forms
Contact and enquiry forms post to FormSubmit (formsubmit.co) → `infinate360businessconsulting@gmail.com`,
with a honeypot, client-side validation, and a WhatsApp alternative. **The first submission triggers a
FormSubmit activation email that must be confirmed before messages are delivered.**

## Deploy
Push to `main` → `.github/workflows/pages.yml` builds, validates and deploys.
Requires Settings → Pages → Source: **GitHub Actions**.

## Rollback
`git revert <commit>` and push, or disable Pages in Settings → Pages.
