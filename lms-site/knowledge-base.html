Knowledge base

Short answers to questions learners ask most, written from trainer replies. Always confirm product behaviour in the current Adobe documentation.

Which AEP ingestion methods are batch and which are streaming? Data ingestion

Connections can be batch or streaming depending on the source (for example S3 is batch, Kafka is streaming). Workflows are batch, because they ingest files such as CSV or Parquet. Data collection through a datastream is streaming, because SDKs send events in real time.

Why does my CSV fail when I drag and drop it into a dataset? Data ingestion

Drag-and-drop dataset upload expects JSON or Parquet. Use the workflow route (source connector or ingest workflow) to bring in CSV files.

Can profiles still stitch if the email is hashed? Identity

Yes. Stitching needs the same value in every dataset, not the raw email. Hash consistently (for example lowercase then SHA-256), mark the field as an identity, and use the matching namespace, such as Email_LC_SHA256.

How do I add a hashed email as a secondary identity to an existing dataset? Identity

Edit the schema linked to the dataset, add a field for the hashed email, mark it as an identity with the Email_LC_SHA256 namespace, and leave it as non-primary. New records that carry the value will then stitch through it. A dataset with only secondary identities can join stitching but needs a primary identity from another source to create a profile.

Is a record schema the same as an XDM Individual Profile schema? Schemas

No. Record describes how the data behaves (profile-level attributes that do not expire). A schema becomes an XDM Individual Profile schema only when you choose that class. The class gives the meaning; record or time series is the behavior.

Do I need to create eventType and timestamp fields in an ExperienceEvent schema? Schemas

No. The XDM ExperienceEvent class already provides eventType, timestamp, _id and identityMap. Map your data to them instead of creating duplicates in a custom field group.

Can the mobile SDK use the same schema as my web SDK? Schemas

It can, but because you will add fields and field groups that only apply to mobile, keeping web and mobile separate is cleaner. Reusable data types such as screen view and app interaction help share structure.

What happens if I enable a schema for Profile by mistake? Profile

It cannot be switched back. If it was a mistake, you need to delete the schema and dataset and ingest again, so check before you toggle it.

What must be true before an attribute can be used in audiences or AJO personalization? Profile

The field must be enabled for Profile, and the dataset must be enabled for Profile. Then it is available in audience logic, AJO journey conditions and AJO content personalization.

When should governance labels and consent be applied? Governance

Apply governance labels at the schema or dataset level before or during ingestion, not after. Ingest consent first so it can be enforced during segmentation and activation.

How do I use a consent tool such as OneTrust with AEP? Governance

Collect consent at the edge with the CMP, send the signal into AEP (usually through the Web SDK), store it in a schema field, enable data usage and privacy rules so AEP respects it, and keep it updated when preferences change.

When do I use a campaign and when a journey in AJO? AJO

Use a campaign for a one-time or scheduled broadcast to a group. Use a journey for automated, step-by-step flows that react to each person's behavior, such as welcome, follow-up and reminder.

What does the backfill months option do? CJA

It tells Adobe how many months of historical data already in the system to reprocess so it can be used for Profile, segments and destinations (AEP), or loaded into reports (CJA). It does not pull data from outside systems.

What is the difference between eVars and props? Adobe Analytics

Props are traffic variables: they describe what happened on a hit and do not persist, which suits pathing. eVars are conversion variables: they persist beyond the hit, which suits attribution. Use events with eVars to measure conversions.

Events are sent with Alloy.js but I see no data in AEP. How do I troubleshoot? Web SDK

Work from the client to the platform: check the Network tab for interact requests to the Edge Network, open the AEP Debugger, confirm the datastream ID, confirm the datastream is active and the Experience Platform service is enabled, check dataset mapping, the XDM schema and identity namespaces, then review ingestion monitoring for failures.

A customer logs in but the profile still shows as anonymous. Where do I look? Web SDK

First check that the authenticated identity (identityMap with authenticatedState and a primary identity) is actually sent after login. Then check the debugger for the namespaces present (ECID, email, CRM ID), the identity graph links, whether the dataset is enabled for Profile, and the merge policy.

How do I design data elements for a large enterprise website? Web SDK

Standardize the data layer and naming, build reusable elements for common values, add validation and defaults for null or undefined, document owner, source, type and definition for each element, and control changes with approvals, versioning and QA.

What is a MarTech backlog and in what order do items depend on each other? Project delivery

It is the prioritized list of requirements, journeys, audiences, integrations, tags, events, schemas, sources, destinations and use cases, tracked with dependencies. Typical order: business requirements, schema design, identity strategy, datasets, ingestion, profile stitching, segmentation, journeys and destinations, activation, QA validation, go-live. Consent mapping and governance sit alongside schema work.
